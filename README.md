# 📺 Аниме-ТВ — 10 каналов

Уютный веб-телевизор в стиле ретро-комнаты с **10 каналами**, переключением передач и поддержкой YouTube-видео.

🌐 Проект можно разместить на **GitHub Pages** и открыть прямо в браузере без установки дополнительных программ.

## ✨ Возможности

* 📺 Ретро-телевизор в стиле старого ТВ
* 🎛️ Пульт управления с 10 каналами
* 🔼 Переключение каналов кнопками ▲ и ▼
* 🎞️ Поддержка YouTube-видео
* 🎬 Поддержка собственных видеофайлов
* 🔊 Управление звуком
* 📱 Адаптация под мобильные устройства
* 🌙 Тёмная тема
* 📡 Эффект помех и переключения каналов
* 💡 Анимация телевизора и комнаты
* 🎨 Пиксельный ретро-дизайн

Самый простой способ:

1. Скачай или клонируй репозиторий.
2. Открой `index.html` в браузере.
3. Выбери канал на пульте.

Для собственного видео положи файл в:

## 📺 Добавление YouTube-канала

В файле `index.html` найди:

```javascript
var CHANNELS=[
```

и добавь:

```javascript
{
  name:"Название канала",
  type:"youtube",
  ids:["VIDEO_ID"]
}
```

Например:

```javascript
{
  name:"Моё аниме",
  type:"youtube",
  ids:["SU46GSrDvKY"]
}
```

Если видео находится по адресу:

```text
https://www.youtube.com/watch?v=SU46GSrDvKY
```

то ID видео:

```text
SU46GSrDvKY
```

> Используй только видео, которые размещены законно и доступны для встраивания владельцем.

## 🚀 Публикация через GitHub Pages

### 1. Создай репозиторий

На GitHub создай новый репозиторий, например:

```text
anime-tv
```

### 2. Загрузи файлы

Загрузи:

```text
index.html
README.md
```

Если используешь собственные видео:

```text
video/
```

### 3. Включи GitHub Pages

Открой репозиторий:

```text
Settings → Pages
```

В разделе **Build and deployment** выбери:

```text
Source: Deploy from a branch
Branch: main
Folder: / (root)
```

Нажми **Save**.

Через некоторое время GitHub Pages создаст адрес сайта:

```text
https://ТВОЙ-USERNAME.github.io/anime-tv/
```
