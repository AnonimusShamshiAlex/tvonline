АНИМЕ-ТВ — 10 КАНАЛОВ, КОТОРЫЕ КРУТЯТСЯ КРУГЛОСУТОЧНО
========================================================

Что внутри:
  index.html                     — сам сайт
  Запусти_на_Windows.bat         — запуск на Windows
  Запусти_на_Mac_Linux.command   — запуск на Mac/Linux
  video/                         — сюда кладёшь свои видеофайлы
  README.txt                     — этот файл

КАК ЗАПУСТИТЬ (ВАЖНО!)
-------------------------
НЕ открывай index.html двойным кликом — YouTube откажется играть
видео с ошибкой "Ошибка настройки видеопроигрывателя / Ошибка 153".
Так происходит потому, что YouTube не встраивает ролики на страницы,
открытые как локальный файл (адрес начинается с file://) — ему
нужен настоящий адрес http://.

Вместо этого запускай сайт через маленький локальный сервер:

  Windows:    дважды кликни  Запусти_на_Windows.bat
  Mac/Linux:  дважды кликни  Запусти_на_Mac_Linux.command
              (на Mac при первом запуске, возможно, попросит
              разрешить запуск в Настройки → Конфиденциальность)

Оба скрипта сами откроют браузер на http://localhost:8000 — вот
эту страницу и используй, а не index.html напрямую. Для скриптов
нужен установленный Python (обычно уже стоит на Mac/Linux; на
Windows можно скачать с https://python.org — при установке
поставь галочку "Add python.exe to PATH").

Если после этого какой-то ОДИН конкретный канал всё равно выдаёт
ошибку — вероятно, автор именно этого ролика запретил встраивание
на другие сайты. Тогда remotе выведет "видео недоступно" вместо
"ошибка настройки", и такой ролик проще заменить на другой ID.

ВАЖНО ПРО ВИДЕО
------------------
Сайт сам ничего не ищет и не скачивает — ни один видеосервис не
позволяет мне подключать чужие серии аниме без разрешения, это
было бы нарушением авторских прав. Зато сайт готов крутить видео
из ДВУХ источников, которые ты подключаешь сам:

  1. YouTube-эмбед — вставляешь ID официального/лицензионного
     ролика (например, с канала студии или Crunchyroll). Эмбед —
     это официальный плеер YouTube, использовать его можно,
     если сам ролик выложен законно.

  2. Свои видеофайлы — кладёшь в папку video/ то, на что у тебя
     есть права (свои записи, лицензионные файлы и т.п.).

КАК НАСТРОИТЬ КАНАЛЫ (2 шага)
--------------------------------
1. Открой index.html в текстовом редакторе (Блокнот, VS Code).
   Найди блок:

       var CHANNELS=[
         null, // 1
         null, // 2
         ...
         null  // 10
       ];

2. Замени null на объект канала. Два формата:

   YouTube (один или несколько роликов подряд по кругу):
       {name:"Опенинги", type:"youtube", ids:["ID_РОЛИКА_1","ID_РОЛИКА_2"]}

   Свои файлы (положи их сначала в папку video/):
       {name:"Мой архив", type:"file", files:["ep1.mp4","ep2.mp4"]}

   ID ролика YouTube — это часть ссылки после "v=" или после
   "youtu.be/". Например, в ссылке
   https://www.youtube.com/watch?v=dQw4w9WgXcQ  ID это dQw4w9WgXcQ

   Пример готового списка на 3 канала:

       var CHANNELS=[
         {name:"Канал 1", type:"youtube", ids:["dQw4w9WgXcQ"]},
         {name:"Мультики", type:"file", files:["ep1.mp4","ep2.mp4"]},
         null, null, null, null, null, null, null, null
       ];

КАК ЭТО РАБОТАЕТ
------------------
Внизу экрана — пульт с кнопками 1–10, каждая подписана названием
канала (если ты его задал). На самом телевизоре тоже есть кнопки
▲▼ для переключения каналов по кругу. Если у канала несколько
роликов/файлов — они крутятся один за другим и потом по новой,
создавая ощущение непрерывного эфира. Кнопка со значком 🔇/🔊 в
углу экрана включает и выключает звук (браузеры не разрешают
автовоспроизведение со звуком без клика пользователя, поэтому
канал сначала запускается без звука).

Ненастроенный канал (null) показывает "нет сигнала".

ОГРАНИЧЕНИЯ
-------------
- Это не настоящий "прямой эфир": ролики просто крутятся по кругу
  с начала, а не синхронизированы по реальному времени суток, как
  на настоящем ТВ. Для настоящей трансляции с одинаковой позицией
  у всех зрителей нужен отдельный сервер — здесь его нет.
- Кнопка звука для YouTube-канала на секунду перезапускает ролик
  (у плеера нет доступа к управлению звуком без перезагрузки).
  Для своих файлов (video/) звук переключается без перезапуска.

ЕСЛИ ЧТО-ТО НЕ ОТКРЫВАЕТСЯ
----------------------------
Запускай через .bat / .command файл (см. раздел выше), а не через
index.html напрямую — иначе YouTube-каналы не заработают. Для
YouTube-каналов нужен интернет. Для своих файлов из video/ —
не нужен, но сайт всё равно должен быть открыт через локальный
сервер (localhost), а не как file://.
